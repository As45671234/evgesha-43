# Евгеша · 43

Фотоальбом вечеринки 21 ноября 2026, Atmosfera Music.
https://as45671234.github.io/evgesha-43/

Оформление чёрно-белое, фотографии в цвете; в шапке галереи
есть переключатель в ч/б.

## Пересборка

Положить новые снимки в `..\фотки` и запустить:

    .\rebuild.ps1

Скрипт заново соберёт веб-версии, перенумерует кадры по времени
съёмки, пересоберёт страницу и выложит всё на GitHub Pages.
Флаг `-NoPush` — собрать локально. Флаг `-Src` — другая папка.

Нужны Python с `pillow` и `pillow-heif`.

## Что где

    index.html              страница, генерируется — руками не править
    tools/build_web.py      оригиналы -> веб-версии + архив
    tools/gen_index.py      photos.json -> index.html (тут же заголовок и даты)
    assets/                 стили и скрипт галереи
    photos/thumb            900 px, сетка
    photos/full             2000 px, просмотр
    photos/dl               2000 px JPEG, кнопка «скачать кадр»
    evgesha-43-photos.zip   архив для кнопки «скачать все»
    photos.json             порядок, размеры, время, заглушки

EXIF и GPS вырезаны из всех снимков: в оригиналах были координаты заведения.
